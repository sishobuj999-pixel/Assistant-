# SIYA

**SIYA** is a personal Android voice agent designed to understand voice commands, plan tasks with an AI model, execute permitted Android actions, and report results by voice.

## Phase 1
- Voice input
- Speech-to-text
- Command routing
- Android intents/actions
- Text-to-speech response

## Planned capabilities
- Secure credential vault using Android Keystore
- Browser and web-task automation
- Official API integrations such as GitHub and Firebase
- Screen-aware automation where Android permissions allow it

## Security
SIYA will not store passwords as plain text. Sensitive credentials should use Android Keystore and platform-supported authentication flows.
